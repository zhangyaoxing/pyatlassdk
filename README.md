# pyatlassdk

Python SDK for the MongoDB Atlas Administration API, generated automatically.

> Everything under `src/pyatlassdk/` is generated by [mongo-atlas-sdk](https://github.com/zhangyaoxing/mongo-atlas-sdk). Do not edit it by hand.

## Installation

```bash
pip install pyatlassdk
```

## Usage

```python
from pyatlassdk import AtlasClient
from pyatlassdk.models.cluster_description20240805 import ClusterDescription20240805

with AtlasClient(public_key="...", private_key="...") as client:
    cluster = client.clusters.create_group_cluster(
        group_id="...",
        body=ClusterDescription20240805(name="demo", cluster_type="REPLICASET"),
    )
```

- Authentication: Atlas API public/private key pair over HTTP Digest.
- Models: pydantic v2 with snake_case fields; serialization uses the original Atlas field names (aliases).
- Resources: 55 resource classes with one method per endpoint, named after `operationId`.

## Regenerating

Run these commands from the `mongo-atlas-sdk` repository:

```bash
uv run mongo-atlas crawl       # fetch the OpenAPI document
uv run mongo-atlas normalize   # normalize it
uv run mongo-atlas pygen       # render templates into pyatlassdk/src/pyatlassdk
```

Then commit in this repository and publish:

```bash
uv build
uv publish
```
